# llm-do-zero ("LLM from zero")

**A character-level language model built from scratch in NumPy — tokenization, embeddings,
hand-written backpropagation, training and text generation — with no pretrained weights and no
autograd.**

[Versão em português](README.md) (the detailed documentation in `docs/` is in Portuguese).

The model learns, one character at a time, to invent plausible Brazilian municipality names from the
5,298 official names published by IBGE (Brazil's statistics institute). It is an educational lab:
small enough to read end to end, complete enough to show every step of how a language model learns.

```text
$ llmzero train --out runs/default        # ~11 s on CPU
$ llmzero generate --run runs/default -n 6 --seed 3 --temperature 0.8
ampo miguel dos do matalinho
nossia
coronel mosal
iguaçu
guaporácia
timpo cochos
```

## Status

Implemented and tested: character tokenizer, sequence-level data split, embedding / linear / tanh
layers with manual forward and backward passes (every gradient checked against central finite
differences), numerically stable cross-entropy, SGD and AdamW, training loop with divergence
detection, temperature sampling, a count-based bigram baseline and five reproducible experiments.

**Not implemented yet:** attention / Transformer — it is the next step (see Roadmap).

## Results

Loss in nats per token (lower is better), from [`results/SUMMARY.md`](results/SUMMARY.md), which is
generated by `llmzero experiments` and never edited by hand:

| Model | Validation | Test |
|---|---:|---:|
| Uniform guess (`ln 42`) | 3.7377 | — |
| Count-based bigram (no neural network) | 2.3851 | — |
| **MLP, 18,746 parameters, 4-character context** | **1.8414** | **1.8190** |

The test set is evaluated once, for the configuration fixed before the experiments.

<p align="center"><img src="docs/img/overfitting.svg" alt="Loss curves showing overfitting with 300 training names" width="720"></p>

With only 300 training names, training loss drops to ~0.8 while validation loss gets worse after step
500: the model memorizes instead of generalizing (24% of samples copy a training name). Weight decay
lowers final validation loss from 3.19 to 2.61, but early stopping is still the best point.

## Run it

Python 3.11+ and NumPy. No GPU, API key or external service.

```bash
pip install -e ".[dev]"
pytest                                    # 37 tests, ~5 s
llmzero -v train --out runs/default
llmzero generate --run runs/default -n 10 --temperature 0.8
llmzero experiments                       # reruns all 5 experiments (~2 min)
```

## Known limitations

- Not a Transformer: fixed context window, no attention.
- Toy scale (18.7k parameters, 42-token vocabulary, ~62k characters of text); numbers are meant for
  comparing variants with each other, not with real models.
- Identical results across runs on the same machine (verified); last digits may differ on another
  CPU/BLAS. One seed per configuration, so small differences have no confidence interval.

## Roadmap

1. Single-head attention with a manual backward pass and gradient check, compared with the MLP on the
   same split.
2. Full Transformer block (multi-head attention, LayerNorm, residuals).
3. BPE tokenizer trained from scratch, for running text.
4. Multiple seeds per configuration.
